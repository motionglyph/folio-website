# Portfolio

Personal UX design portfolio, built with Next.js (App Router) and Tailwind CSS.

## Stack
- [Next.js](https://nextjs.org) — App Router, TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
app/
├── page.tsx        → Home
├── layout.tsx       → Shared layout / metadata
└── globals.css       → Global styles
```

More pages (About, individual case studies under `works/`) are being added incrementally.
